Roles & permissions

One row per capability, one column per role. Every section has an Access permission (enter & view it) and a Manage permission (act within it) — so a role can be made read-only by granting Access without Manage. High-stakes capabilities are broken out as their own toggles and marked. Permissions are deny-by-default: a new role starts with nothing checked.

Super Admin bypasses this matrix entirely. It always holds every permission and can never be locked out, so it has no editable toggles — its column is shown for reference only. The matrix governs every other role.

Legend & notes

How to read this matrix
Access enter / view a section Manage act within a section Danger high-stakes PII personal data SA-only elevated Always not editable
  • Access vs Manage. Access lets a role enter and view a section; Manage lets it act there. Granting Access without Manage makes the role read-only — exactly what the example Support Agent has on Customers.
  • Super Admin bypasses the matrix. It always holds every permission and can never be locked out, so it has no editable toggles — its column is reference-only.
  • account.self is always-on for every operator and is not shown as a toggle: own profile, password, personal notification preferences, My Work, global search and the dashboard.
  • The marked rows are the dangerous ones. Destructive, financial, security and config capabilities (delete, void, GDPR, deployment, impersonation, staff & role management, billing/product/commission config, WordPress bulk updates, Maavelus statements) carry a coloured stripe and a chip. Grant them sparingly.
  • forms.view_submissions is its own toggle because it exposes PII submitted through public forms — separate from building forms.
  • Migration safety. The Staff column is access-identical to today — every section's Access + Manage plus staff-level actions are ON, and every super-admin-only capability is OFF — with one deliberate change: webhook-retry moves into settings.integrations (super-admin-only), so it is no longer a staff capability.
